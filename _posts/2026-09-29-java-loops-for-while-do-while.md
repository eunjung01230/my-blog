조건문을 사용하면 조건에 따라 실행할 코드를 선택할 수 있다.

그렇다면 같은 작업을 여러 번 실행해야 할 때는 어떻게 해야 할까?

예를 들어 어떤 동작을 5번 반복한다고 생각해 보자.

```java
System.out.println("1번 했습니다.");
System.out.println("2번 했습니다.");
System.out.println("3번 했습니다.");
System.out.println("4번 했습니다.");
System.out.println("5번 했습니다.");
```

5번 정도라면 직접 작성할 수도 있다.

하지만 100번, 1,000번 반복해야 한다면 같은 코드를 계속 작성하는 것은 비효율적이다.

Java에서는 이런 반복 작업을 처리하기 위해 **반복문**을 사용한다.

이번 수업에서는 `for`, `while`, `do-while` 반복문의 기본 구조를 살펴보고, 반복문 안에 조건문을 함께 사용하는 방법을 배웠다.

---

## for문

`for`문은 **초기식, 조건식, 증감식**을 이용해 반복 횟수를 제어하는 반복문이다.

기본 형태는 다음과 같다.

```java
for (초기식; 조건식; 증감식) {
    실행 코드
}
```

각 부분에는 다음과 같은 역할이 있다.

| 구성 | 역할 |
|---|---|
| 초기식 | 반복에 사용할 변수의 초기값을 설정 |
| 조건식 | `true`이면 반복하고 `false`이면 종료 |
| 증감식 | 한 번 반복한 후 변수의 값을 변경 |
| 실행 코드 | 조건을 만족하는 동안 반복할 코드 |

가장 기본적인 형태로 1부터 5까지 출력해 보면 다음과 같다.

```java
for (int i = 1; i <= 5; i++) {
    System.out.println(i);
}
```

여기서는 각각 다음 의미를 가진다.

```text
int i = 1  → i를 1부터 시작
i <= 5     → i가 5 이하인 동안 반복
i++        → 한 번 실행할 때마다 i를 1 증가
```

결과는 다음과 같다.

```text
1
2
3
4
5
```

## for문은 어떤 순서로 실행될까

`for`문의 세 부분이 한 줄에 작성되어 있어 처음에는 실행 순서가 헷갈릴 수 있다.

```java
for (int i = 1; i <= 5; i++) {
    System.out.println(i);
}
```

실제 흐름은 다음과 같다.

```text
① 초기식
int i = 1
    ↓
② 조건식 확인
i <= 5 ?
    ↓ true
③ 코드 실행
System.out.println(i)
    ↓
④ 증감식
i++
    ↓
② 조건식으로 돌아감
    ↓
   ...
    ↓
조건식이 false
    ↓
반복 종료
```

중요한 점은 **초기식은 처음 한 번만 실행**된다는 것이다.

그 이후에는

```text
조건식 → 실행 코드 → 증감식
   ↑                    ↓
   └────────────────────┘
```

순서가 반복된다.

`i`가 증가하다가 조건식 `i <= 5`가 `false`가 되는 순간 반복문을 빠져나간다.

---

## 벤치프레스 5회 반복하기

수업에서는 벤치프레스를 5번 반복하는 상황으로 `for`문을 연습했다.

반복문을 사용하지 않는다면 다음과 같이 작성할 수 있다.

```java
System.out.println("성원님 1번 했습니다~");
System.out.println("성원님 2번 했습니다~");
System.out.println("성원님 3번 했습니다~");
System.out.println("성원님 4번 했습니다~");
System.out.println("성원님 5번 했습니다~");
```

같은 구조가 계속 반복된다.

`for`문을 사용하면 이를 하나의 반복 구조로 만들 수 있다.

```java
System.out.println("성원님 벤치프레스 5회 실시할게요~");

for (int i = 1; i <= 5; i++) {
    System.out.println("성원님 " + i + "번 했습니다~");
}
```

여기서 `i`는 단순히 반복 횟수를 세는 역할만 하는 것이 아니다.

현재 몇 번째 반복인지 나타내는 값으로도 사용할 수 있다.

```text
i = 1 → 성원님 1번 했습니다~
i = 2 → 성원님 2번 했습니다~
i = 3 → 성원님 3번 했습니다~
i = 4 → 성원님 4번 했습니다~
i = 5 → 성원님 5번 했습니다~
```

즉, 반복문을 사용하면 **반복되는 코드 자체를 줄이면서 현재 반복 횟수도 활용할 수 있다.**

---

## 반복문 안에서 조건문 사용하기

반복한다고 해서 매번 같은 동작만 해야 하는 것은 아니다.

수업에서는 벤치프레스 예제에 다음 조건을 추가했다.

> 홀수 번째에는 횟수를 말하고, 짝수 번째에는 침묵한다.

[이전 글]({{ site.baseurl }}{% post_url 2026-09-29-java-conditionals-if-switch %})에서 배운 `if`문을 `for`문 안에 넣으면 된다.

```java
for (int i = 1; i <= 5; i++) {

    if (i % 2 == 0) {
        System.out.println("침묵함...");
    } else {
        System.out.println("성원님 " + i + "번 했습니다~");
    }
}
```

짝수는 2로 나누었을 때 나머지가 0이다.

따라서 다음 조건으로 짝수인지 확인할 수 있다.

```java
i % 2 == 0
```

실행 결과는 다음과 같다.

```text
성원님 1번 했습니다~
침묵함...
성원님 3번 했습니다~
침묵함...
성원님 5번 했습니다~
```

실행 흐름을 나누어 보면 다음과 같다.

```text
for문으로 i 반복
       ↓
 i % 2 == 0 ?
    ↙       ↘
 true      false
  ↓          ↓
침묵함     횟수 출력
    ↘       ↙
      i++
       ↓
다음 반복으로 이동
```

여기서 확인할 수 있는 중요한 점은 **반복문과 조건문은 서로 따로 사용하는 문법이 아니라 함께 사용할 수 있다는 것**이다.

`for`문이 전체 반복 횟수를 결정하고, 그 안의 `if`문이 매 반복마다 어떤 코드를 실행할지 결정한다.

## while문

`while` 역시 조건이 `true`인 동안 코드를 반복한다.

기본 형태는 다음과 같다.

```java
while (조건식) {
    실행 코드
}
```

예를 들어 0부터 2까지 출력한다면 다음과 같이 작성할 수 있다.

```java
int num = 0;

while (num < 3) {
    System.out.println("0~2까지 반복 출력 : " + num);
    num++;
}
```

실행 결과는 다음과 같다.

```text
0~2까지 반복 출력 : 0
0~2까지 반복 출력 : 1
0~2까지 반복 출력 : 2
```

`while`문에서는 조건식을 먼저 확인한다.

```text
num = 0
   ↓
num < 3 ?
   ↓ true
코드 실행
   ↓
num++
   ↓
조건식으로 돌아감
   ↓
num < 3 ?
   ↓
  ...
   ↓ false
반복 종료
```

따라서 **처음부터 조건이 `false`라면 실행 코드는 한 번도 실행되지 않는다.**

예를 들어 다음 코드를 보자.

```java
int num = 5;

while (num < 3) {
    System.out.println(num);
    num++;
}
```

처음부터 `5 < 3`이 `false`이므로 반복문 내부로 들어가지 않는다.

## do-while문

`do-while`문도 `while`과 마찬가지로 조건식을 사용해 반복을 제어한다.

하지만 실행 순서에 중요한 차이가 있다.

기본 형태는 다음과 같다.

```java
do {
    실행 코드
} while (조건식);
```

`while`은 **조건을 먼저 확인**하지만, `do-while`은 **코드를 먼저 실행한 다음 조건을 확인**한다.

```java
int num = 0;

do {
    System.out.println("0~2까지 반복 출력 : " + num);
    num++;
} while (num < 3);
```

실행 흐름은 다음과 같다.

```text
num = 0
   ↓
코드 실행
   ↓
num++
   ↓
num < 3 ?
 ↙       ↘
true    false
 ↓        ↓
다시 실행  종료
```

따라서 `do-while`은 조건과 관계없이 **실행 코드를 최소 한 번은 실행한다.**

---

## while과 do-while의 차이

이 차이는 처음부터 조건을 만족하지 않는 값을 사용하면 명확하게 확인할 수 있다.

먼저 `while`이다.

```java
int num = 5;

while (num < 3) {
    System.out.println("현재 값 : " + num);
    num++;
}
```

처음 조건부터 다음과 같다.

```text
5 < 3 → false
```

따라서 아무것도 출력되지 않는다.

이번에는 같은 조건을 `do-while`로 작성해 본다.

```java
int num = 5;

do {
    System.out.println("현재 값 : " + num);
    num++;
} while (num < 3);
```

이번에는 결과가 다르다.

```text
현재 값 : 5
```

조건 `5 < 3`은 처음부터 `false`이지만, `do` 블록이 먼저 실행되기 때문이다.

두 반복문의 차이를 정리하면 다음과 같다.

| 반복문 | 조건 확인 시점 | 최초 조건이 false라면 |
|---|---|---|
| `while` | 실행 전 | 0회 실행 |
| `do-while` | 실행 후 | 1회 실행 |

즉,

```text
while
조건 확인 → 실행

do-while
실행 → 조건 확인
```

이라는 순서의 차이가 있다.

## for, while, do-while 비교

세 반복문 모두 코드를 반복한다는 목적은 같다.

차이는 **반복을 어떻게 제어하느냐**에 있다.

| 반복문 | 특징 |
|---|---|
| `for` | 초기식·조건식·증감식을 한곳에서 관리 |
| `while` | 조건을 먼저 확인하고 반복 |
| `do-while` | 먼저 한 번 실행한 후 조건 확인 |

특히 `for`문은 다음과 같이 반복 횟수를 제어하는 요소가 한 줄에 모여 있다.

```java
for (int i = 1; i <= 5; i++)
```

그래서 **몇 번 반복할지 명확한 상황**에서 구조를 파악하기 쉽다.

반면 `while`과 `do-while`은 조건을 중심으로 반복을 제어한다.

이번 수업 단계에서는 세 문법을 무조건 특정 상황에 맞춰 외우기보다 **조건을 언제 검사하고, 값이 언제 변하며, 언제 반복이 종료되는지** 실행 흐름을 이해하는 것이 먼저이다.

---

## 반복문에서 증감식을 확인해야 하는 이유

반복문에서는 반복에 사용하는 값이 제대로 변하고 있는지 확인해야 한다.

예를 들어 다음 코드를 보자.

```java
int num = 0;

while (num < 3) {
    System.out.println(num);
}
```

`num`의 초기값은 `0`인데 반복문 내부에서 값이 변하지 않는다.

따라서 조건은 계속 다음과 같다.

```text
0 < 3 → true
0 < 3 → true
0 < 3 → true
...
```

조건이 계속 `true`이므로 반복문이 끝나지 않는다.

따라서 다음과 같이 반복할 때마다 값을 변경해야 한다.

```java
int num = 0;

while (num < 3) {
    System.out.println(num);
    num++;
}
```

반복문을 작성할 때는 단순히 조건식만 보는 것이 아니라 다음 세 가지를 함께 확인해야 한다.

```text
어디에서 시작하는가?
        ↓
언제까지 반복하는가?
        ↓
반복할 때 값이 어떻게 변하는가?
```

이 흐름을 이해하면 반복 횟수가 예상과 다르거나 반복이 종료되지 않는 문제를 찾기 쉬워진다.

## 정리

반복문은 같은 작업을 여러 번 실행해야 할 때 사용한다.

`for`문에서는 **초기식 → 조건식 → 실행 코드 → 증감식**의 흐름을 이해하는 것이 중요하다.

```text
초기식
  ↓
조건식 ←────────┐
  ↓ true        │
실행 코드       │
  ↓             │
증감식 ─────────┘
  ↓
조건식 false
  ↓
종료
```

반복문 안에는 조건문을 넣을 수도 있다.

이번 벤치프레스 예제에서는 `for`문으로 5번을 반복하면서 `if`문으로 홀수와 짝수에 따라 실행할 코드를 다시 나누었다.

그리고 `while`과 `do-while`의 가장 중요한 차이는 **조건을 확인하는 시점**이다.

```text
while     → 조건 확인 후 실행
do-while  → 실행 후 조건 확인
```

따라서 `do-while`은 처음부터 조건이 `false`여도 코드가 최소 한 번 실행된다.

조건문이 **어떤 코드를 실행할지 선택하는 문법**이었다면, 반복문은 **코드를 언제까지 다시 실행할지 결정하는 문법**이라고 볼 수 있다.

다음에는 반복되는 작업을 하나의 코드 블록으로 묶어 필요할 때 호출할 수 있는 **메서드(Method)**를 살펴본다.
