AI를 활용해서 프로그래밍을 독학으로 공부하려면, 코드를 짜기 전에 노트북부터 몇 가지 준비가 필요해요. 오늘은 제가 실제로 세팅한 것들을 하나씩 정리해볼게요.

## 1. 전체 세팅 흐름 한눈에 보기

```mermaid
flowchart LR
    A[Git 설치] --> B[GitHub 계정 연동]
    B --> C[VS Code 설치]
    C --> D[확장 프로그램 설치]
    D --> E[Claude 데스크탑 앱 설치]
    E --> F[터미널 기본 환경 설정]
```

## 2. Git 설치 및 GitHub 계정 연동

|항목 | 왜 필요한가|
|---|---|
|Git 설치| 내 컴퓨터에서 버전 관리를 시작하려면 가장 먼저 필요|
|GitHub 계정 생성| 내가 작업한 내용을 인터넷에 올리고 보관할 공간이 필요해서|
|GitHub와 로그인 연동| 내 컴퓨터에서 만든 커밋을 GitHub 계정으로 올릴 수 있게 연결하기 위해|

```mermaid
flowchart LR
    A["내 컴퓨터<br/>(Git 설치)"] -->|로그인 연동| B["GitHub 계정<br/>(원격 저장소)"]
```

## 3. VS Code 설치 및 확장 프로그램

|항목 | 왜 필요한가|
|---|---|
|VS Code 설치| 코드와 글을 편하게 작성하고 편집할 에디터가 필요해서|
|Claude 관련 확장 프로그램 설치| 에디터 안에서 바로 AI(클로드)의 도움을 받으면서 작업하기 위해|

## 4. Claude 데스크탑 앱 설치

|항목 | 왜 필요한가|
|---|---|
|Claude 데스크탑 앱 설치| 브라우저를 따로 열지 않아도 컴퓨터에서 바로 클로드를 사용하기 위해|

## 5. 터미널/기본 환경 설정

|항목 | 왜 필요한가|
|---|---|
|터미널(PowerShell 등) 사용법 익히기| Git 명령어를 입력하거나 프로그램을 실행하려면 꼭 필요|

## 정리하며

Git 설치 → GitHub 계정 연동 → VS Code 설치 → 확장 프로그램 설치 → Claude 데스크탑 앱 설치 → 터미널 환경 설정, 이 순서로 노트북을 세팅했어요. 처음엔 항목이 많아 보이지만, 결국은 "코드를 저장할 곳(Git/GitHub)"과 "코드를 작성하고 AI의 도움을 받을 곳(VS Code/Claude)"을 준비하는 과정이라고 생각하면 훨씬 이해하기 쉬워요.
