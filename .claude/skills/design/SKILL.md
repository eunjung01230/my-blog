# 블로그 포스트 디자인

학습 노트를 작성하거나 정리할 때 아래 규칙을 적용해줘.

이 스킬은 새로운 글을 작성하는 역할이 아니라,
작성 중인 블로그 포스트의 구조와 표현을 보기 좋게 정리하는 역할을 한다.

## 1. 기본 원칙

- 프로그래밍 입문자가 다시 읽기 쉽게 구성한다.
- 화려하게 꾸미는 것보다 가독성을 우선한다.
- 한 문단이 너무 길어지지 않게 적절히 나눈다.
- 불필요한 이모지는 사용하지 않는다.
- 중요한 내용만 강조한다.

## 2. 제목과 소제목

글의 내용을 구분할 때 Markdown 제목을 사용한다.

- 큰 주제가 바뀌면 `##`
- 그 안의 세부 내용은 `###`
- 소제목을 너무 많이 만들지 않는다.

## 3. 핵심 용어

- 처음 등장하는 중요한 기술 용어는 **굵게 표시**한다.
- 같은 용어를 반복해서 강조하지 않는다.

## 4. 명령어와 코드

- Git 명령어, Java 코드 등은 코드 블록으로 표시한다.
- 짧은 명령어, 파일명, 코드 이름은 인라인 코드를 사용한다.

## 5. 표와 목록

- 여러 개념을 비교할 때는 표를 사용한다.
- 작업 순서가 중요한 내용은 번호 목록을 사용한다.
- 단순한 내용까지 억지로 표나 목록으로 만들지 않는다.
